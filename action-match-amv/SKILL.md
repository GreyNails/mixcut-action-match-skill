# 动作衔接混剪

把不同来源的战斗剪成可读的动作链，再让切镜、镜内命中和原片声音共同组织节奏。
交付可播放成片、可回溯时间线、素材来源与实际完成的检查结果；用户要封面时再制作封面。

## 先确定本次约束

- 从用户和现有工程读取素材范围、音乐、片长、画幅、画面内容、原声偏好及交付目录。
- 用户要求保留旧版时，在新版本目录工作；记录旧成片和关键工程文件的校验值，完成后复核。
- “只用打斗”包含进攻、格挡、闪避、战斗脚步和紧接攻击的准备/回收；排除独立风景、对白和脱离交锋的人物展示。
- 音乐时长、尾声处理、帧率和画幅按当前任务确定，不沿用案例的固定数值。
- 只在缺失信息确实阻止工作时询问；素材检查、分析、可逆编辑和已授权的成片制作可以继续进行。

## 随附工具按任务选用

- 音乐瞬态与概览图：`scripts/analyze_music.py`，参数用 `--help` 查看；默认覆盖整首音乐，确认口播尾段后再限制分析区域。
- 原片时间戳联系表：`scripts/contact_sheet.py`，用低密度概览定位后对动作边界密抽。
- 可复现输出：`scripts/amv.py` 的 `prepare → check → render → mix → assemble → validate`；配置、缓存与时间映射见 [CLI说明](scripts/CLI.md)。
- 用例与结构：[V2配方](examples/v2/README.md) 含全部时间线和文件名映射，不附番剧或音乐。先测试代表镜头，再渲染整片。
- 无素材技术自检：`scripts/smoke_test.py`。合成素材验证管线正确性，不能替代动画观感审查。

## 1. 拆参考片，区分事实与复刻方法

先查看完整分段抽帧，再对关键接缝、接触帧和声音事件加密检查。
至少分开记录：切点、动作准备、动作爆发、实际接触、收势和声音瞬态。

- 说明每组相邻镜头共享什么：动作阶段、屏幕方向、身体轴线、武器路径、构图或攻防关系。
- 区分原动画内部连续动作、跨素材剪接和后加画面效果。
- 只有成片混音时，不能确认某个瞬态来自原片音效、音乐鼓声还是外加效果。
- 图像与频谱能支持部分判断；未实际听看时，不宣称逐声源听辨或完整实时审片。
- 复刻参数是当前工程的选择，不写成参考作者的真实插件和工程参数。

## 2. 扩大素材池，再筛出动作单元

按篇章或集数并行扫描，先建立低密度概览；对候选动作抽取连续帧复核。
“更多素材”通过新动作关系增加丰富度，不靠重复片段或无关人物镜头增加数量。

每个候选至少保留：

- 源文件、集数/篇章、原片入出点、角色、核验状态。
- 动作阶段和可用的接触/发力锚点；不确定时标记估计或留空。
- 屏幕方向、身体姿态、景别、主体位置、武器/刀光形状。
- 推荐前后动作、保留理由、排除原因及字幕/裁切限制。

动作单元应保有准备、爆发和结果中必要的阶段，不只截最亮的一帧。
复核候选末尾是否带入原片下一镜头，避免剪到字幕、对白或静止反应镜。

## 3. 先排动作链，再分配镜头长度

优先连接可读的动作因果和动势；颜色、人物主题可辅助关联。
配对时同时看前镜尾部和后镜头部的一小段连续帧，不能只比较两张静帧。

常用链条包括：

- 翻滚中段 → 同相位倒置身体 → 落地。
- 脚部蹬压 → 身体突进 → 武器接触。
- 低伏横移 → 同方向近身斩 → 受击结果。
- 水轮/衣摆/双刀圆弧 → 相近中心与尺度的旋转动作。
- 格挡 → 反击 → 回弹，而非反复堆放无准备的爆炸画面。

保留少量原片连续交手，让镜头内部承担多个重音。
按音乐段落安排疏密变化；更密的鼓点不要求每一下都换场景。
水平翻转、裁切和短效果只能修正已有匹配的小差异，不能制造不存在的动作连续性。

## 4. 使用实际音乐事件

在指定音乐上检测频谱和能量变化，保留事件时间、强度、估计类别及证据。
将周期/BPM 用作节奏结构参考；不要把均分网格伪装成逐个真实鼓点。
人声辅音、器乐起音也会产生峰；不确定类别保留为“瞬态候选”。

分别决定哪些事件由切镜承接，哪些由镜内发力或接触承接。
音乐缺少鼓声的间奏/尾声按动作句和乐句组织，不补造鼓点统计。
按输出帧率将最终切点与动作目标量化为整数帧，并保留原始检测时间。

## 5. 对齐动作，同时保住原声关系

先摆正接触或发力锚点，再调整入点、出点及前后阶段速度。
需要变速时，画面与原片声音使用同一个源时间→成片时间映射。
处理声音速度时保持所需音高；实现工具有倍率范围时，将大倍率分解为合法链。

仅在原声起音证据可靠、峰无歧义且视觉锚点已复核时，考虑有限微调。
若首个可解码画面已经接触、原声自然同步，就不要再按粗略 hit 估计推迟声音。
允许的偏移以当前帧率、起音精度和听看结果确定；案例中的“最多两帧”不是普适定律。

围绕动作使用短原声包络，保留必要破风和回响，并避免把整条原配乐叠到新音乐上。
打击成分掩膜与滤波只能压低部分持续声，不能称为完全分离的干净音效。
混音留出峰值空间，适当给接触声让位；导出音乐、原片动作声和完整混音便于修订。

## 6. 先验证代表段，再完成整片

先渲染能覆盖主要风险的代表片段：高密度段、低密度段、变速、原声、字幕裁切和关键动作链。
查看最终裁切、镜像、变速后的画面；源片联系表不能替代成片结果。
发现问题时优先调整源入出点、动作顺序或少量相邻帧数，保留不受影响的已确认时间段。
修改后更新源边界、时间映射、声音位置与对应检查，不能只改视频而遗漏原声。

完成全片后检查时间线连续性、帧数、音轨、完整解码、黑帧、裁切、重复源区间和音画偏移。
计数节奏覆盖时，对切点和镜内锚点引用的同一音乐事件去重。
报告技术检查、图像抽查与实时听看各自实际覆盖的范围；数字通过不等于观感已被证明。

## 7. 交付与按需制作封面

保留成片、短预览、时间线、逐镜源索引、音乐事件、混音和重建参数。
剪辑软件交换文件若引用已变速片段，说明效果已烘焙；未经导入实测不要宣称完全兼容。
说明主要变化、已验证内容和仍需听看确认的部分，不夸大复刻水平。

用户要人物拔刀封面时，先从真实视频核验不同人物的握柄、出鞘或拔刀阶段，保存原帧与时间来源。
按用户指定画幅制作；不规则漫画分镜可以用不等面积斜切、墨线毛边和局部跨格构图，避开机械四等分。
需要图像生成/编辑时，遵守当前可用图像工具的使用规则，并保留参考原帧与提示词。
生成式排版可能重绘细节，不能称为原帧逐像素不变；最终检查角色、手、刀与边界，旧封面按约定保留。
