# 动作素材筛选与衔接

用于建立候选库、排序动作链以及诊断“切在拍上却不顺”的接缝。

## 将素材描述到可以配对

候选记录应指向可复查的源片区间。以下是分析字段，不要求工具一定使用相同字段名。

| 内容 | 有效描述 | 作用 |
| --- | --- | --- |
| 身份与来源 | 文件、篇章、集数、人物、入出点 | 回溯、统计与去重 |
| 动作阶段 | 蹬地前压低 → 蹬地 → 前冲 | 寻找前后阶段 |
| 屏幕方向 | 主体右→左，攻击由左上落向右下 | 保住动势与攻防关系 |
| 身体轮廓 | 倒置、头低腿高、俯身、双臂展开 | 跨人物相位匹配 |
| 几何中心 | 刀弧中心位于中下，主体占画面约一半 | 减少重新寻找主体 |
| 景别与对象 | 脚部近景、刀柄特写、双人中景 | 对应视觉关注对象 |
| 事件锚点 | 实际接触/发力时间及估计精度 | 镜内卡点 |
| 可用边界 | 出点必须在下一原片机位前 | 防止带入多余画面 |
| 音画状态 | 原声有无、候选峰歧义、字幕位置 | 提前识别处理成本 |
| 核验状态 | 已看哪些源帧、哪些待确认 | 不把算法候选当已核验素材 |

“某角色很帅”不能代替动作标签。针对“只用打斗”，把蓄势、握柄和回收与前后攻击一起判断：有战斗功能的准备动作可以留，独立站姿介绍不能只因持刀就算打斗。

## 分层扫描，避免只围绕少数熟悉场景取材

1. 建立素材清单，记录时长、帧率、音轨、分辨率和来源分组。
2. 按篇章或集数分配扫描范围；多人并行时各自写独立候选文件，统一阶段再合并。
3. 概览用于定位战斗，候选区间再密抽，命中和接缝按原生帧时间复核。
4. 保存排除原因：对白、独立反应、动作太短、源中已切镜、字幕遮挡、与已选区间重叠等。
5. 用覆盖表发现明显遗漏，再补有衔接价值的动作；集数覆盖不是需要机械平均分配的配额。

新加入的篇章应提供新姿态、武器路径、景别或攻防关系，才能提高丰富度。若两个候选只有颜色不同而动作任务相同，未必都值得使用。

## 四类连接分别判断

| 类型 | 例子 | 应核对 | 常见误判 |
| --- | --- | --- | --- |
| 同场因果连续 | 格挡 → 反击 → 对手退后 | 原动作次序、受力方向、等待长度 | 为增切镜数打碎本来连贯的动作句 |
| 跨场动作匹配 | 白天倒置翻滚 → 夜间继续翻滚 | 相位、旋转趋势、主体位置和尺度 | 两张图都倒立，但运动方向相反 |
| 阶段补全 | 下落 → 脚落地 → 再次蹬起 | 谁在移动、何时接触、下一步预期 | 先出现结果，再切回同一攻击的准备 |
| 图形/语义连接 | 水轮 → 火环；握刀 → 刀锋露出 | 形状、中心、攻击对象与意图 | 把相同刀光线条误称为完全同向挥刀 |

构图或主题关联较弱时可以使用，但在分析中如实说明强度。不要把“水→雾”的材质变化与经过逐帧核验的翻滚相位匹配写成同一种精确程度。

## 配对时查看过程

查看 A 尾部和 B 头部各一小段连续帧；片长取决于帧率与动作速度，通常需要覆盖切点两侧约 0.2–0.5 秒。极快动作应检查相邻原生帧。

依次判断：

1. A 提出的动作预期是什么，B 是否延续或完成它？
2. 主体在屏幕什么位置，观众需要重新移动多远才能找到它？
3. 身体和刀的运动方向是否延续？背景移动是否造成相反的假象？
4. 两边动作在加速、接触还是回收？只匹配轮廓是否会造成速度突变？
5. 攻击者和目标是否换边？来袭物的方向是否与躲避动作相容？

若前镜刚完成斩击，后镜又回到同一击发生前，优先修改顺序或裁掉重复准备。不能依靠更亮的闪光掩盖因果倒退。

## 调整顺序

优先更换候选或源入出点，其次调整时长和阶段速度，然后才考虑裁切、镜像和短效果。

- 裁切应稳定主体位置，同时保住刀尖、来袭物和接触对象。以统一大裁切去字幕可能剪掉真正的动作信息。
- 镜像用于有明确方向收益的镜头；检查文字、左右手持刀、可辨识服饰和同场关系，避免同一动作内翻转轴线。
- 变速要保留准备与结果。极短镜头里硬塞完整长动作会使肢体和刀路无法阅读。
- 短亮度、色偏、模糊只强调已有爆发；去掉效果后连接应仍能解释。
- 叠化适合形状和构图稳定的过渡。复杂近身交锋中两套身体叠在一起常会降低可读性。

## 段落密度与动作句

可以先按动作语汇排段：脚步与翻滚、低伏突进、水火圆弧、双刀攻防、密集连击、收束。再与音乐的能量变化协调，而非先固定每镜长度再塞素材。

高密度段也需要景别和长短变化。连续两三次格挡可以留在一个镜头中；此时卡的是镜内动作。尾段无鼓点但仍要求纯打斗时，可用较长的持续攻防和最后一击收束，不必插风景。

## 本次案例带来的具体修正

- 脚步镜末尾原片已切回全身：提前源出点，让脚部匹配完整成立。
- 头槌镜开头是静止背影：提前结束等待，保留身体开始扑向对手的过程。
- 双刀圆弧末尾人物摊臂收势：在弧线还运动时接下一个圆弧，避免势能突然停住。
- 同一斩击被排成“穿过敌人 → 切颈”：交换相邻镜头，保持总时长不变，并将原切点重音转为镜内动作。

这些修正体现的是检查方法，不是其他项目要套用的时间码或角色顺序。
