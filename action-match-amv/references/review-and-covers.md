# 成片复核、局部修订与封面

用于从代表段推进到完整交付，也用于用户反馈后的可控修订。

## 先看代表段

选择能暴露不同问题的片段，不必随机抽很多相似镜头：

- 最密集连击：是否保住动作准备，连续换场后主体是否仍容易寻找。
- 翻滚/脚步/圆弧的关键接缝：是否动作阶段相接，刀尖和受击对象是否被裁掉。
- 最明显变速：前后倍率变化是否破坏挥刀感，原声是否跟同一映射。
- 有字幕的源素材：最终裁切后是否仍有字，放大是否损伤动作信息。
- 最短与最长镜头、开头与结尾：是否意外带入下一原片机位或多余静帧。

检查对象应是已执行裁切、镜像、变速和效果的渲染结果。源片首中末帧只是初筛，不能证明最终连接成立。条件允许时正常速度看画面、只听音频、再声画合看；若环境无法播放，保留预览并如实标记未试听。

## 把反馈落到可定位的改动

先记录问题在成片与源片中的位置、可观察现象和拟改内容。

| 现象 | 优先修正 |
| --- | --- |
| 镜头末尾突然变为静态反应 | 源出点提前，检查音频包络与尾帧 |
| 跨人物翻滚突然倒转 | 检查运动相位与方向，换候选或改切点 |
| 切口踩拍、真正接触却偏离 | 重定位镜内锚点，选择合理事件并分段变速 |
| 原声好像比接触晚 | 核验原生接触帧和起音，检查是否错误微调 |
| 动作发生顺序倒退 | 改相邻镜头次序，在原总时长内重新分配 |
| 过度密集看不清 | 让部分重音留在镜内，给关键动作多留数帧 |

已确认的大部分时间线应尽量冻结。在局部镜头或一对相邻镜头内调整源边界、帧数和锚点，更新相关派生值后仅重渲染受影响单元。除非用户要求重新编排全片，不要因一处修正让求解器重新分配所有切点。

保存修正原因和前后值，保证同样输入可以重建同样结果。缓存键应覆盖镜头参数和渲染实现，不能仅用候选 ID 导致旧片段被误用。

## 保留旧版

新建版本目录保存工程、片段、预览、分析和成片。旧版用户文件不覆盖；对旧成片、关键时间线和混音保存并复查校验值。输出文件命名反映版本和用途，避免“final2_final”一类难以区分的名称。

用户只改封面时保持视频不变；只改某处节奏时不顺手重写已完成的其他输出。

## 技术检查与观感检查分开报告

| 检查层 | 应验证 | 不能据此宣称 |
| --- | --- | --- |
| 时间线 | 连续整数帧、入出点合法、动作锚点在源范围内、无越界 | 动作自然流畅 |
| 素材来源 | 来源路径、集数/篇章覆盖、是否重复源区间 | 人物和招式都被正确辨认 |
| 成片完整性 | 宽高、帧率、帧数、总长、完整解码、意外黑帧 | 每帧构图都理想 |
| 音轨 | 有可解码音频、有效声道、峰值、响度、母带同步 | 每个声音都是干净打斗音效 |
| 图像复核 | 裁切、字幕、动作阶段、接缝前后帧、实际修正点 | 已完成实时逐帧审片 |
| 正常速度听看 | 节奏层次、动作可读性、原声残留、变速听感 | 未审查段落同样通过 |

黑帧检测应关注有效画面区，避免把设计黑边算异常。源区间重复可以报告、按用户要求去重；有意重复作为回扣时记录用途，不把“绝不重复”变成所有混剪的硬规则。

音画精度与可变帧率尤其要留意：依据真实 PTS 定位源片；解码验证实际起始帧，而不是假定 `-ss` 后第一帧就是数学上的入点。

## 可继续编辑的交付

交付清单按任务规模选择：成片、代表预览、素材候选、逐镜源索引、整数帧时间线、音乐事件、原声处理参数、分轨和构建入口。

导出的剪辑交换文件需说明引用的是原片还是已变速的片段。烘焙片段便于重排，但不等于软件中保留了原始可编辑速度曲线。未经目标软件导入实测，描述为“已生成交换文件，未做该软件导入验证”。

分析说明应将观察、解释、参数和验证分开；没有听辨的部分保持明确，不用“全部丝滑”“每一下零误差”替代证据。

## 从真实拔刀画面制作人物封面

只在用户要求封面时开展。先确认画幅、是否文字和视觉方向；已有明确偏好直接沿用。

### 选帧

1. 从实际素材或成片出现的角色中寻找握柄、刀刃出鞘及紧接拔刀的动作。若要求“拔刀”，不能用任意持刀姿势冒充。
2. 检查连续帧确认动作与身份，然后选手、刀柄、鞘口或刀刃关系清楚的一帧。
3. 为每帧保留源文件、原片时间/PTS、角色、近似成片位置；保存未经生成式修改的原始截图。
4. 对比人物尺度、刀路与色彩，选择彼此互补的构图。不要只为凑人数使用模糊或被字幕遮挡的帧。

### 不规则漫画排版

用户不喜欢规整拼接时，使用不等面积面板、斜向分割、锯齿或墨线毛边，形成一条主要阅读方向。人物脸、握刀手与刀柄不被接缝切断；刀路可以靠近边界形成跨格动势，但不能把不同人物的手或武器混合成错误结构。

避免只是把四个等大矩形旋转一点。边界和面板大小要有变化，同时保留呼吸空间；速度线只帮助动作方向，不应覆盖脸和拔刀细节。4:3 是本次案例画幅，其他任务按用户要求设置。

### 图像工具与真实性

使用当前环境可用的图像生成/编辑工具，遵守工具对参考图、编辑方式和返回结果的要求。提交原帧前先实际查看；参考图和提示词保留在项目中。

如果工具会生成或重绘像素，说明输出是“基于原片截图的生成式拼贴排版”，不要声称每个角色细节均与原帧逐像素一致。检查刀鞘、手指、脸、服饰标记、人物数量、面板边界、比例和意外文字。

用户要求原帧像素完全保真时，使用其授权且符合当前工具规则的确定性合成方式；不要默默用生成式结果替代。若工具无法满足，先把已选原帧和排版方案保存，明确剩余限制。

### 封面交付

保存最终 PNG、原始截图、来源清单与生成/排版记录；修订封面时保留上一版。查看实际像素尺寸并验证比例，不能只因为提示词写了“4:3”就报告输出正确。

本次示例从四名人物的真实拔刀镜头选帧，先做规整拼贴，再按反馈改成不规则漫画面板。可迁移的是“真帧核验 → 参考排版 → 检查生成结果 → 保留旧版”的流程，不是固定这四名角色或相同面板位置。
