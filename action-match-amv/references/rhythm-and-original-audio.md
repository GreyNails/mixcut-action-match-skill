# 节奏事件、动作锚点与原片声音

用于把动作链放进音乐，以及处理同步变速、原声微调和结果统计。

## 一条时间线上至少有四种事件

| 事件 | 定位依据 | 可以承担什么 |
| --- | --- | --- |
| 音乐事件 | 指定音乐中的频谱/能量变化，必要时听辨 | 鼓点、器乐起音、乐句强调 |
| 切点 | 前镜结束、后镜开始的整数输出帧 | 更新信息与空间 |
| 视觉锚点 | 发力、刀刃相碰、手掌击鼓、脚触地等 | 镜内重音 |
| 原声起音 | 原片局部音频中的实际起音证据 | 与相应动作构成一个声画单位 |

这四种时间可以相邻，也可能承担不同任务。新镜先入场，半秒后才接触，是有效的准备→命中；切口在鼓点上但画面还慢慢抬刀，未必形成动作重音。

## 音乐检测提供候选，不提供语义真值

同时分析多个频段的正谱通量与短窗能量上升，可帮助区分低频重击、中频击打和高频节奏。记录检测步长、时间基准、峰强度与分类的不确定性。

- BPM、自相关或周期估计适合了解主要脉冲和段落结构，不足以确定每个实际鼓点。
- 固定 BPM 网格可作为辅助编辑尺，但要与“音频中检测到的事件”分开保存。
- 高强度峰可能是歌声辅音、效果或器乐；不要把所有峰都命名为底鼓。
- 音乐鼓点缺席时，不为维持密度添加虚构事件。
- 保留未量化的时间与输出帧；量化误差可以解释，不应藏在“精确对齐”的说法里。

输出帧率为 `F` 时，目标帧通常取 `round(t * F)`，实际目标时间为该帧除以 `F`。非整数帧率应使用有理数时间基，不能长期累加近似小数造成漂移。

动作次序和可读性先确定，再从附近可靠音乐事件中选择切点与镜内目标；不要允许算法为了吸附高峰，把动作阶段拉到无法辨认。

## 用可复现的时间映射绑定声画

设源入点 `a`、源出点 `b`、源动作锚点 `h`；成片镜头开始于 `T`，时长 `D`，希望动作在镜内 `u` 时命中。

对锚点两侧分别采用速度倍率：

```text
v_before = (h - a) / u
v_after  = (b - h) / (D - u)

source t <= h: output = T + (t - a) / v_before
source t >  h: output = T + u + (t - h) / v_after
```

`v > 1` 表示加速。此公式要求锚点位于源片内部，`0 < u < D`。首帧已经接触的镜头应单独处理边界，不能用零分母构造变速。

将同一映射应用于画面和原片声音。声音使用保持音高的时间伸缩；如工具单级倍率有限，分解倍率后串联处理。不要让视频分段变速、声音仍以单一倍率播放。

帧数、源裁切与音频样本数都可能发生舍入。逐镜保存整数帧长度，音频按该时长裁齐或补齐；拼接时检查镜头间没有缝隙或重叠。填充尾帧可以修复不足一帧的技术差异，不能拿长时间静帧补齐缺失动作。

若合理速度范围内无法命中目标，先调整源边界或选附近的另一个音乐事件。动作连贯性也可以优先，明确记录未精准命中的锚点，由切点和相邻动作承担节奏。

## 微调声音前先检查视觉估计

在视觉锚点附近分析原片中高频变化与局部能量上升；低频最大峰不能单独证明是接触声。每个候选保留附近多个峰、证据分数、源区间内外与歧义状态。

只有峰与该动作阶段相符、证据可靠且没有多峰歧义时，才考虑把起音稍微移动。分数是检测证据强度，不是“这个声音肯定是刀刃相撞”的概率。

原声自然同步往往比粗略抽帧 hit 更可靠。例如一次踢脸，粗略 hit 晚于真实接触约 65 ms；原生首个接触帧和原声峰本来一致。正确修正是更新视觉锚点并取消声音延迟，不能为了迎合错误的 hit 移动原声。

允许偏移需结合帧率、检测精度、动作速度与听看结果。V2 曾用高可信无歧义条件和最多两输出帧作为保守上限，这只是该工程策略。证据不够时保留自然同步，音频峰记空；空值不代表没有声音。

## 原声混合保留包络

把破风上升、接触瞬态与短尾响视为动作单元。可以让破风稍早进入、余响跨过切点，但接触声仍应对应实际接触。

可选处理链：

1. 解码候选原声，按视频时间映射变速并对齐。
2. 用打击成分掩膜和必要频段过滤压低持续原配乐，检查人声与音乐残留。
3. 以动作锚点构造短包络，给准备声、接触和尾响分配不同强度。
4. 音乐只在需要处轻微让位，避免每一下都把歌曲压得忽大忽小。
5. 混合后控制峰值，保留音乐、动作声与完整混音三个可单独修改的输出。

掩膜不是声源语义分离，原配乐打击乐也可能被保留，人声辅音也可能穿过。处理强度过大还会产生破碎、金属化或抽吸感。没有实际试听时，应写“信号处理与数值检查完成”，不要写“音效完全干净”。

## 统计与验证

为音乐事件设置稳定 ID；将切点和镜内锚点各自引用的事件集合求并集：

```text
节奏覆盖数 = |切点事件集合 ∪ 镜内动作事件集合|
额外镜内覆盖数 = |镜内动作事件集合 - 切点事件集合|
```

不要把两种计数直接相加导致同一个重音重复统计。动作声事件数、镜头数、音乐事件数和分段变速数也不能互相替代。

本次 V2 的可复核结果是：223 个动作单元、43 集、5 个篇章；188 个切点事件加 98 个额外镜内事件，覆盖 286 个不同音乐瞬态；206 处原片动作声、98 段分段变速、21 处有限原声微调。这些是已完成案例的数据，不是新项目的指标或默认配置。

导出后检查音轨是否存在、声道是否有实际能量、响度/峰值是否合理，以及从成片解码的音频是否与母带保持时间关系。相关系数和零偏移检查可以发现编码/拼接错位，不能证明每次刀声都听起来舒服。最终观感需要正常速度听看。
