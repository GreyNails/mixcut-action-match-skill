# 案例：多篇章纯打斗 V2

这份 skill 来自一个具体制作流程：分析参考混剪中的动作接续和原片打斗声卡点，使用更多集数与篇章制作新版本，保留旧版，再从成片素材中提取不同角色的拔刀帧制作封面。这里记录可迁移的决策，也标出仅属于本例的参数。

## 素材不是按集数排列

先分组扫描、再密抽候选，给每段记录角色、阶段、屏幕运动方向、身体轴线、景别、刀光形状和发力/接触点。最终使用立志篇20集、无限列车篇6集、游郭篇6集、锻刀村篇9集、柱训练篇2集，共43集、223个互不重叠的原片区间。

“只用打斗”仍允许连续交锋中的举刀、脚步、回弹；不单独使用风景、聊天、人物站姿展示或家庭结尾。更多集数是素材池的结果，不能代替镜头之间的关联。

## 节奏分两层

本例不是用一个固定 BPM 网格切完整首歌。对音乐做频谱打击成分与分频段正向通量分析，保留450个优选瞬态；再由动作链决定使用哪些时刻。

最终188个事件由切镜承接，98个额外事件由镜内动作锚点承接，去重后为286个。镜内对齐不要求再换一个场景。主歌与尾段给动作留空间；约30秒的最后高潮使用50个动作单元。

190.775秒后的段落主要是口播/收尾，未补造“鼓点”。原音乐约214.1秒，本例输出210.1秒，裁掉末端约4秒近静音；这是本例选择，新任务应遵守用户指定的长度。

## 原声与画面同步调整

用98段前后两段变速，把接触点摆到输出帧上。原片声音使用相同时间映射，通过合法倍率的 `atempo` 链保持音高，再使用短包络、频段处理和打击成分掩膜压低持续配乐。21处有充分证据的原声起音才做最多两帧的微调。

“用了同一个映射”不代表输出声峰自动精确：`atempo` 会移动或涂抹瞬态，需对变速后的音轨再观察与试听。掩膜也不能把原片声音变成干净分离音效。

脚踢镜是一个具体纠错：原生首个可解码接触帧为280.655375秒，声音峰为280.655333秒，实际自然同步。原先按粗略 hit 标记增加63.6 ms延迟反而错误，因此取消延迟，按首个接触画面落切点。

## 最终复核为什么重要

初步首中末抽帧后，再检查最终裁切、镜像、变速的结果，集中修了以下问题：

- 雪地交锋与脚步特写尾部混入下一景别：提前源出点。
- 头槌开头仍有静止背影：推进源入点，但冻结全片其他时间槽。
- 三次击鼓里两次只切点对拍、掌心接触却偏离：重新分配镜内前后速度。
- 天元双刀进入摊臂收势：在刀弧仍延续时切到下一组圆弧。
- 蛇柱同一斩击先结果后接触：交换两个相邻动作段，总长度仍1秒，将原切点改为镜内命中。

V2原工作站输出完成6303帧、完整解码、音轨相关性与旧版SHA核验；这些是技术证据。联系表和边界抽查不等同于实时看完和听完，不把节奏事件数量作为观感评分。

## 封面：从规整四格到漫画分镜

从实际使用素材中筛出善逸、炼狱、实弥、无一郎刀刃正在出鞘的帧，以手、刀镡、鞘口关系为判据。不是随便拿持刀或挥刀截图代替拔刀。

第一版规则四格显得机械。修订版保留横向4:3，将中心十字拆成错位交汇的斜切、多边形、锯齿和墨线毛边；速度线集中在边缘，避免遮住手和出鞘缝隙。原片截图另外保存，imagegen产物不声称像素完全不变。

## 公共工具与原工作站工程的区别

公共包保留相同的时间线字段和所有选材区间，但移除了机器路径、账号信息与素材文件。工作目录、源文件、音乐可重新绑定，NVENC不适用时可用CPU。

公共渲染器把输入严格限制在源出点内，不使用长冻结尾帧掩盖缺素材；仅允许采样舍入恰少一帧时补一帧并记报告。它用合成工程和真实单镜验证过，但未从公开脚本重新跑完全部223镜头。编码器、音效峰值、首解码PTS处理和采样细节可能造成与原成片不同的字节或观感，需要按代表片段先检查。
